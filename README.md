# UMass Hangout

Campus social app from the Group 6 check-in: login/register, profiles with tags, groups, events, group chat, search, and file sharing.

## Run

```powershell
cd C:\project\umass-hangout
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)
